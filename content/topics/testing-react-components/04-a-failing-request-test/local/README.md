# Shop with tests

A small React shop built like the CS300 Capstone starter, for the CS300 Practice topic **Testing React components**.
Its data is in `public/data/products.json`, and `BrowserRouter` is in `src/main.jsx`.

## Run it

```bash
npm install
npm run dev
```

## Test it

```bash
npm test
```

`npm test` runs every `.test.jsx` file under `src` once with Vitest, in a simulated browser page from jsdom, and prints which tests passed.
